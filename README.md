# SQL DVD Rental Assignment

This repository contains the SQL queries and analysis performed on the `dvdrental` sample database. The project demonstrates filtering, ordering, and logical operations on film and customer data.

## Queries Performed
The following queries were executed on the database:

1. **Basic Selection:** Displaying film titles and descriptions, ordered alphabetically.
2. **Length Filter:** Extracting films with a length between 60 and 75 minutes.
3. **Cost Analysis:** Filtering films based on specific rental rates and replacement costs.
4. **Customer Info:** Retrieving the last name of the customer named 'Mary'.
5. **Complex Filtering:** Advanced filtering excluding specific rental rates for short films.

## Included Files
- `sorgu1.csv` to `sorgu5.csv`: The result sets for each query exported in CSV format.
